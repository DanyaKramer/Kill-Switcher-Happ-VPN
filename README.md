# Happ Kill Switch

Утилита для Ubuntu Desktop, которая управляет исходящим трафиком через `nftables` и защищает соединение Happ. В режиме «Только VPN» разрешены loopback, адрес сервера VLESS и трафик через TUN-интерфейс Happ. В режиме полной блокировки разрешён только loopback.

> Это ранняя версия. Сначала проверяйте её в снимке виртуальной машины. Утилита не может гарантировать защиту от сбоев ядра, неверной настройки или трафика вне сетевого пространства имён Linux.

## Установка для разработки

```bash
git clone https://github.com/DanyaKramer/Kill-Switcher-Happ-VPN.git && cd Kill-Switcher-Happ-VPN
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
pytest
```

Поддерживается Python 3.10 и новее. В Ubuntu 22.04 для TOML используется пакет `tomli`. Для интерфейса используется Textual. Модульные тесты не требуют root и не меняют firewall.

## Первый запуск и импорт JSON

Запустите панель без аргументов:

```bash
happ-killswitch
```

Выберите «Импорт JSON». В `nano` вставьте JSON, скопированный правым кликом по серверу в Happ. В Ubuntu Terminal используйте Ctrl+Shift+V; сохраните Ctrl+O, Enter и выйдите Ctrl+X. Мастер понимает распространённые форматы Xray и sing-box. Если в JSON несколько серверов VLESS, выберите тот, который подключён в Happ.

JSON обрабатывается локально во временном файле с ограниченными правами, затем удаляется. В конфиг сохраняются только адрес, порт и транспорт выбранного сервера — UUID и ключи не сохраняются. Файл конфигурации создаётся с правами `0600`.

Если конфигурация уже создана, запуск панели запросит права администратора. Настройка выполняется от обычного пользователя, а команды управления сетевыми правилами — от администратора. Для повторного импорта используйте кнопку «Импорт JSON» в панели.

Чтобы добавить пункт в меню приложений Ubuntu, выполните из каталога проекта:

```bash
python3 scripts/install_desktop_launcher.py
```

Ярлык запускает TUI в GNOME Terminal. Для постоянной установки команда `happ-killswitch` должна находиться в системном `PATH` или в виртуальном окружении проекта.

## Команды

```bash
happ-killswitch                         # открыть панель
happ-killswitch setup                   # повторно импортировать JSON из Happ
sudo happ-killswitch check              # проверить профиль и правила
sudo happ-killswitch on                 # включить режим «Только VPN»
sudo happ-killswitch lock               # заблокировать весь исходящий трафик
sudo happ-killswitch off                # отключить защиту
happ-killswitch status                  # показать состояние
```

Команды `on`, `lock`, `off`, `check` и `watch` сохраняют английские имена для использования в терминале. TUI показывает названия и подсказки на русском.

Утилита не запускает и не останавливает Happ. Подключите Happ в режиме TUN, затем включите режим «Только VPN». Наличие интерфейса TUN не подтверждает, что туннель передаёт трафик; проверьте внешний IP отдельно.

## Работа защиты

Таблица приложения называется `happ_killswitch`; другие таблицы не изменяются. По умолчанию исходящий трафик IPv4 и IPv6 блокируется. Правила применяются одним пакетом `nft`. Команда `off` удаляет только таблицу приложения. Если программа завершится аварийно, правила ядра останутся активными.

Сторожевой процесс блокирует сеть после повторного исчезновения TUN и обновляет IP-адреса сервера, пока туннель поднят. Он проверяет наличие интерфейса, но не способен подтвердить, что туннель передаёт данные.

Для systemd установите проект в `/opt/happ-killswitch`, а конфигурацию — в `/etc/happ-killswitch/config.toml` с правами `0600`. Скопируйте unit-файл в `/etc/systemd/system/`, выполните `systemctl daemon-reload` и включите `happ-killswitch-watchdog.service`. Инструкция проверки Ubuntu VM находится в `docs/VM_TEST_PLAN.md`.

Для испытаний используйте VMware-консоль: включение Lock может отключить SSH. Если потеряли сеть, выполните `sudo happ-killswitch off` в консоли или восстановите снимок VM.
